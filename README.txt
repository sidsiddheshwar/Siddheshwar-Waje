TRAVEL WITH SID — AFFILIATE WEBSITE STARTER

FILES
- index.html: complete responsive website. No frameworks or paid services needed to run it.

PREVIEW LOCALLY
1. Download and unzip the folder.
2. Double-click index.html to open it in a browser.

CUSTOMIZE PRODUCTS
1. Open index.html in a text editor (VS Code is free, or use TextEdit in plain-text mode).
2. Find: const products = [
3. Each product has name, category, emoji, description, affiliateUrl and imageUrl.
4. Replace affiliateUrl: "" with your actual approved affiliate tracking URL.
5. To add an image, set imageUrl to a direct image URL you are allowed to use. Keep it empty to show the emoji.
6. Save and refresh the browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named travel-with-sid-gear (or another name).
3. Upload index.html to the repository root and commit the change.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the published URL to appear in Settings → Pages. It will usually look like https://YOUR-USERNAME.github.io/travel-with-sid-gear/
7. Open that URL on your phone and test category filters, search, language toggle and every product link.

IMPORTANT
- This starter contains demo products and blank affiliate URLs. It does NOT contain active affiliate links or official product images.
- Replace blanks with links from affiliate programs you have joined and been approved for.
- Follow each program's current rules for link disclosure, pricing, images, trademarks and social promotion.
- Do not invent discounts, prices, reviews, or claims of personal testing.
- Add a privacy policy if you later collect visitor information or use analytics/cookies.
